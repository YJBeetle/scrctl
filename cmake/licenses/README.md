# GNU dependency license texts

These unmodified GNU license texts accompany Windows dependency DLLs. They do
not change scrctl's Apache-2.0 license. Retrieved from the official FFmpeg
repository's n7.1 tag (COPYING.GPLv2, COPYING.GPLv3, COPYING.LGPLv2.1 and
COPYING.LGPLv3): https://github.com/FFmpeg/FFmpeg/tree/n7.1

The FFmpeg build configuration and dependency package versions in each artifact
identify the binaries used. License texts alone do not replace corresponding
source or other redistribution requirements.
